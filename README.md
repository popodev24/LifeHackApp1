# LifeHack or Myth? — Android Quiz App

## About
An Android quiz app built with Kotlin that tests users on whether 
popular life hacks are fact or myth.

## Features
- Welcome screen with Start button
- 5 question quiz with Hack or Myth answers
- Instant feedback with explanations
- Score screen with performance message
- Full answer review screen
- Retry option

## How to Run
1. Clone the repo in Android Studio
2. Run on emulator or physical device (API 21+)
